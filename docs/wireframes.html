Peru Online / Design evidence / Version 0

A country coming online.
Planning the reading experience.

Initial proposed layouts for a history of the internet in Peru, 1997–2025. Each page has a 1200-pixel desktop study and a 390-pixel mobile study. These original diagrams show hierarchy, content placement and responsive reading order.

These are wireframes, not screenshots of the completed site. Content labels are illustrative. Human prototype feedback has not yet been collected; use the feedback form to record actual reviews and changes.

01 Overview02 Timeline03 Connections04 Sources & project

01 / Overview

A split desktop hero pairs the introductory story with a globe. On mobile, the summary and timeline link come first, followed by the illustration and stacked chapter routes.

02 / Timeline

Period controls precede the chronology. Desktop dates and source links flank the narrative. Mobile places the date, text and source in a single readable order.

03 / Everyday connections

Three topics connect infrastructure to daily life: public cabinas, mobile access and the digital divide. The proposed desktop columns become stacked illustrated sections on mobile.

04 / Sources & project

Sources use consistent attribution fields. Project scope and method occupy a desktop side column and follow the bibliography on mobile.
